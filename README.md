# ✨ 커스텀 성향표 · 프로필 카드 생성기

게임 성향표를 기본 예시로 제공하지만, 질문·항목·색상·이미지를 자유롭게 바꿔 취향표, 자기소개 카드, 모집글, 커뮤니티 프로필 등 다양한 형식으로 사용할 수 있는 클라이언트 전용 웹 앱입니다.

백엔드나 데이터베이스 없이 동작하므로 입력한 내용은 별도 서버에 저장되지 않습니다.

## 주요 기능

- **두 가지 레이아웃**: 평가표 중심의 타입 A와 Q&A 카드 중심의 타입 B
- **세로·가로 모드**: 가로 모드에서 타입 B는 2열 카드 구성, 타입 A는 표와 코멘트 영역의 폭 조절 지원
- **자유로운 편집**: 질문·체크 항목·프로필 정보의 추가, 삭제 및 순서 변경
- **프로필 커스텀**: 아바타 업로드·크롭, 인장 위치, 구분선, 배경 설정
- **스타일 커스텀**: 테마 프리셋 5종, 상세 색상, 카드 배경 이미지
- **스티커 기능**: 스티커 배치, 앞/뒤 레이어 변경, 이동·크기 조절, 회전 및 좌우 반전
- **식별코드 공유**: 현재 편집 내용을 UTF-8 Base64 코드로 복사하고 다시 불러오기
- **PNG 저장**: 편집 도구를 숨긴 상태로 고해상도(2배율) PNG 다운로드

## 실행 방법

별도 설치 과정이 필요 없습니다.

1. 이 저장소를 내려받거나 복제합니다.
2. `index.html`을 최신 웹 브라우저에서 엽니다.

PNG 내보내기는 CDN으로 불러오는 `html2canvas`를 사용하므로, 처음 실행할 때는 인터넷 연결이 필요합니다.

## 사용 방법

1. 상단에서 타입 A/B와 세로/가로 모드를 선택합니다.
2. 프로필, 표 또는 Q&A 카드의 제목·내용을 원하는 주제로 수정합니다.
3. 컬러 커스텀과 자유 이미지로 디자인을 꾸밉니다.
4. `식별코드 발급`으로 내용을 복사하거나, `트위터용 이미지 저장 (PNG)`으로 이미지를 저장합니다.

게임 성향표 외에도 독서·음악·창작 취향표, 스터디/길드 모집 카드, 팬 커뮤니티 자기소개 등으로 활용할 수 있습니다.

발급된 식별코드는 생성 시점부터 **7일 동안** 유효합니다.

## 파일 구조

```text
.
├── index.html          # 메인 UI와 모달 구조
├── styles.css          # 테마, 레이아웃, 내보내기 전용 스타일
├── README.md
├── HANDOFF.md          # 유지보수·인수인계 문서
└── js/
    ├── app.js          # 상태와 UI 이벤트·렌더링
    ├── storage.js      # 식별코드 생성·파싱·만료 검증
    ├── layerManager.js # 자유 이미지 레이어 관리
    └── export.js       # PNG 내보내기
```

## 기술 스택

- HTML5
- CSS3 (CSS Variables)
- Vanilla JavaScript (ES Modules)
- [html2canvas 1.4.1](https://html2canvas.hertzen.com/)

## 유의사항

- 식별코드에는 아바타와 배경·스티커 이미지 데이터까지 포함될 수 있어, 이미지가 많거나 크면 코드가 길어집니다.
- 식별코드는 영구 저장 수단이 아닙니다. 7일 이후에는 다시 불러올 수 없습니다.
- PNG 내보내기 화면에는 편집용 버튼·드래그 핸들이 자동으로 포함되지 않습니다.
